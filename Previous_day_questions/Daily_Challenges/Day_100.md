## 1. Koko Eating Bananas

This problem builds intuition for binary search on the answer, where instead of searching over array indices, you search over a range of possible numeric results. Related topics: Binary Search, Arrays, Greedy.

Koko has returned from the market with several piles of bananas and wants to finish all of them before her guards come back. There are `n` piles in total, and the i-th pile contains `piles[i]` bananas. The guards will return after exactly `h` hours, and until then Koko is free to eat at her own pace.

Koko picks a fixed eating speed of `k` bananas per hour. Every hour, she selects one pile and eats up to `k` bananas from it. If the chosen pile has fewer than `k` bananas remaining, she finishes that pile and simply waits for the rest of the hour instead of starting another pile.

Koko would rather eat slowly, so your job is to help her pick the smallest possible value of `k` that still lets her clear every pile within `h` hours.

### Task

Find the minimum integer eating speed `k` such that Koko can finish all the piles within `h` hours.

### Input

- First line contains two integers `n` and `h` - the number of piles and the number of hours available.
- Second line contains `n` integers, `piles[0], piles[1], ..., piles[n-1]` - the number of bananas in each pile.

### Constraints

- `1 <= n <= 10^4`
- `1 <= piles[i] <= 10^9`
- `n <= h <= 10^9`

### Output

Print a single integer - the minimum eating speed `k` that lets Koko finish all the bananas within `h` hours.

### Example 1

**Input:**
```text
piles = [3,6,7,11], h = 8
```

**Output:**
```text
4
```

### Example 2

**Input:**
```text
piles = [30,11,23,4,20], h = 5
```

**Output:**
```text
30
```

## 2. Days Until a Warmer Temperature

This problem teaches the stack technique for efficiently finding the next greater element in a sequence. Related topics: Arrays, Stack.

A weather station has recorded the daily temperature readings for a stretch of `n` days, stored in an array where the i-th value gives the temperature on that day.

For every day in the record, you need to figure out how many days a person would have to wait until a strictly warmer day occurs. If no such warmer day exists afterward, the wait for that day should be recorded as `0`.

### Task

For each day `i`, compute the number of days until a strictly warmer temperature is recorded; if no warmer day follows, output `0` for that day.

### Input

- First line contains an integer `n` - the number of days.
- Second line contains `n` integers, the temperature recorded on each day.

### Constraints

- `1 <= n <= 10^5`
- `30 <= temperatures[i] <= 100`

### Output

Print `n` space-separated integers - for each day, the number of days to wait for a warmer temperature, or `0` if there is none.

### Example 1

**Input:**
```text
temperatures = [73,74,75,71,69,72,76,73]
```

**Output:**
```text
1 1 4 2 1 1 0 0
```

### Example 2

**Input:**
```text
temperatures = [30,40,50,60]
```

**Output:**
```text
1 1 1 0
```
