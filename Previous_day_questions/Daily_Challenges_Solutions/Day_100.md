## 1. Koko Eating Bananas

### Solution

```cpp
#include <bits/stdc++.h>
using namespace std;

bool canFinish(vector<int>& piles, int h, long long k) {
    long long hours = 0;

    for (int bananas : piles) {
        hours += (bananas + k - 1) / k;

        if (hours > h)
            return false;
    }

    return true;
}

int minEatingSpeed(vector<int>& piles, int h) {
    long long low = 1;
    long long high = *max_element(piles.begin(), piles.end());

    while (low < high) {
        long long mid = low + (high - low) / 2;

        if (canFinish(piles, h, mid))
            high = mid;
        else
            low = mid + 1;
    }

    return (int)low;
}
```

- **Time Complexity:** `O(n log M)`, where `M` is the maximum pile size.
- **Space Complexity:** `O(1)`

The solution uses Binary Search on the answer. The possible eating speed lies between `1` and the largest pile size.

For a given speed `k`, the required hours are calculated using ceiling division:

`hours += (piles[i] + k - 1) / k`

If Koko can finish within `h` hours, we try a smaller speed. Otherwise, we increase the speed.

**Optimized solution:** Yes. Binary Search reduces the search over possible speeds from a linear search to `O(log M)` candidate speeds, with `O(n)` work for each candidate.

**Inbuilt function:** `std::max_element()` is used to find the largest pile.

## 2. Days Until a Warmer Temperature

### Solution

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> dailyTemperatures(vector<int>& temperatures) {
    int n = temperatures.size();
    vector<int> answer(n, 0);
    stack<int> st;

    for (int i = 0; i < n; i++) {
        while (!st.empty() &&
               temperatures[i] > temperatures[st.top()]) {
            int previousDay = st.top();
            st.pop();

            answer[previousDay] = i - previousDay;
        }

        st.push(i);
    }

    return answer;
}
```

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

The solution uses a Monotonic Stack. The stack stores indices of days whose next warmer temperature has not yet been found.

When the current temperature is greater than the temperature at the index on top of the stack, the current day is the next warmer day for that previous day. The difference between the indices gives the number of days to wait.

Each index is pushed onto the stack once and popped at most once.

**Optimized solution:** Yes. A brute-force approach would take `O(n²)` time in the worst case. The monotonic stack reduces the time complexity to `O(n)`.

**Inbuilt function:** `stack::push()`, `stack::pop()`, `stack::top()`, and `stack::empty()` are used for stack operations.
